## 👨‍💻 Sobre mim

Trabalho na linha de frente de sistemas financeiros: investigo incidentes, traduzo regras de negócio complexas (FIDC, CNAB, remessas e retornos bancários) em requisitos técnicos, e já contribuí para **reduzir em ~30% os tickets recorrentes** de suporte através de melhorias de processo.

Hoje aplico essa visão de negócio no desenvolvimento de **APIs e aplicações web**, com foco em **C#, .NET, Angular, TypeScript e SQL Server**. Meu diferencial não é só código — é entender *por que* o sistema precisa se comportar de determinada forma antes de escrever a linha que resolve.

- 🔭 Atualmente aprofundando **APIs REST com .NET** e **Angular**
- 🎓 Cursando **Análise e Desenvolvimento de Sistemas**
- 🎯 Buscando oportunidade como **Desenvolvedor Júnior**
- 💬 Fale comigo sobre sistemas financeiros, integrações bancárias ou vagas de dev
